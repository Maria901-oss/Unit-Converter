## Unit Converter App
# Overview

Unit Converter App is a simple Android application built using Kotlin and XML. It allows users to convert values between different units easily. The app works completely offline and does not require any backend or internet connection.

It also provides customization features like theme switching, decimal precision control, and different calculation modes for better user experience.

# Features
1. Unit Conversion

Users can convert values between multiple unit types.
Supported conversions include common measurement categories such as length, weight, temperature, and others.

2. Theme Switching

Users can switch between light and dark themes.
Helps improve readability based on user preference.

3. Decimal Precision Control

Users can set how many decimal places they want in results.
Useful for more accurate or simplified outputs.

4. Calculation Modes

The app supports different calculation styles:
• Thousand seperator
• Scientific mode
• General decimal

Users can select the mode based on their requirement.

5. Offline Functionality

No backend or internet connection is required.
All conversions are handled locally inside the app.

# Tech Stack
Android Development

• Kotlin
• XML (UI Design)

Architecture

• Simple offline logic
• No backend integration

# How It Works
User selects a unit category
User enters value
User selects input and output units
System calculates conversion instantly
Result is shown with selected decimal precision
Project Goal

The goal of this app is to provide a fast, simple, and offline unit conversion tool with customization options for better usability.
